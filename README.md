# Frango no Pote | Dashboard de Análise Comercial

## Sobre o projeto

Projeto de Business Intelligence desenvolvido no Power BI para analisar o desempenho comercial de uma rede fictícia de alimentação com 60 lojas, utilizando uma base de 600 mil registros de vendas distribuídos ao longo de 24 meses.

O objetivo é transformar dados transacionais em indicadores gerenciais que apoiem a análise de faturamento, comportamento dos produtos e desempenho das unidades.

## Tecnologias utilizadas

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Excel
- Modelagem de dados

## Indicadores e análises desenvolvidos

**Visão Executiva**
- Faturamento total e evolução mensal
- Variação mensal do faturamento (MoM%)
- Desempenho comercial por região
- CMV, lucro bruto e margem bruta estimados

**Desempenho Comercial**
- Ranking das lojas por faturamento
- Quantidade de unidades vendidas
- Receita média por unidade
- Faturamento e volume de vendas por produto
- Análise ABC e gráfico de Pareto
- Análise de pedidos e ticket médio provisório

## Principais resultados

- Análise de 600 mil registros de vendas.
- Faturamento consolidado de aproximadamente R$ 33 milhões.
- Comparação do desempenho de 60 lojas.
- Identificação de seis produtos comercializados.
- Identificação de que os três produtos de maior faturamento representam aproximadamente 79% da receita.
- Desenvolvimento de dashboards interativos com filtros por período.

## Observações metodológicas

Os dados representam uma operação fictícia.

O CMV foi estimado em 32% do faturamento para fins de simulação, não representando custos reais observados.

O ticket médio depende da identificação correta dos pedidos e deve ser interpretado considerando as limitações dos códigos disponíveis.

## Objetivo profissional

Este projeto foi desenvolvido para aplicar conhecimentos de análise de dados, modelagem, DAX e visualização de informações, demonstrando como soluções de Business Intelligence podem apoiar decisões comerciais e gerenciais.
